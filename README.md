# Наша история — шаблон временной линии

## Как добавить изображения
1. Положи все 27 файлов изображений в папку `images` рядом с `index.html`.
2. Названия файлов должны совпадать с прописанными в HTML, включая пробелы, скобки, кириллицу и регистр.
3. Открой `index.html` в браузере, чтобы проверить сайт.

В HTML имена изображений уже прописаны и URL-кодируются для надёжной работы на GitHub Pages.

## Как изменить текст
Для каждого воспоминания найди в `index.html` блок `<article class="moment ...">` и отредактируй:
- `<p class="date">` — дату;
- `<h2>` — заголовок;
- `<p class="caption">` — подпись.

## Как опубликовать на GitHub Pages
1. Создай репозиторий на GitHub.
2. Загрузи `index.html` и папку `images` с изображениями.
3. В репозитории открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch, затем ветку `main` и папку `/ (root)`.
5. Сохрани настройки и дождись публикации.

Важно: сайт на GitHub Pages обычно общедоступен по ссылке. Если скриншоты содержат личную переписку, не публикуй их без согласия второго человека. Даже если ссылка не размещена публично, любой, кто её получит, может открыть сайт.
